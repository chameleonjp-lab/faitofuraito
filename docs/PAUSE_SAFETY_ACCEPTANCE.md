# 停止・復帰の追加受入検査

対象基点: `d0bde0ad1922f665b71d11aa1f624ed032ceb5c1`。`SPEC.md` の60Hz固定更新、1秒を超える描画停止の一時停止、入力解除、明示再開、停止中の本体・弾・敵・演出停止を対象にする。仕様や実装は変更しない。

## 今回の不足と追加

既存の `aircraft-parity.spec.ts` は手動停止時の装填・墜落演出と再開を検査していた。今回追加する `pause-recovery.spec.ts` は、大きなRAF時刻差とネイティブ `WEBGL_lose_context` の停止・復旧経路を専用に検査する。

- Viteの実際のmainモジュールへ、検査ブラウザ内だけで深いコピーの読取口を付加する。本体ファイル、公開bundle、状態更新、pause/resume関数は変更しない
- NormalモードでPlaywrightの制御時計から製品のframeコールバックへ1.5秒の差を渡し、製品の停止判定を通す。更新停止前後の全GameState、弾の位置/寿命、敵のAI時計、弾数、得点、入力保持を照合する。非公開WeakMap内の補充タイマーなどはこの読取口の対象外
- 復旧通知だけでは進まないこと、明示再開後に世界が進み、古い押下で射撃が再開せず、新しい押下は受理されることを検査する
- 表示時計だけ止まって内部の位置・弾・AI・装填・得点・時刻が変わる負例と、キー/指/レバーの保持が復活する負例を同じ検査関数が拒否する
- 外向き通信はnavigation前に遮断・模擬応答し、本番の開始集計やランキングへ送信しない

## 証拠の区分

追加した制御時計の検査は停止判定と状態/入力の安全性の証拠であり、実時間FPS、GPU性能、実iPhone Safari、ネイティブなタブ離脱やOSの復元を実証しない。既存の実時間・描画・操作検査はそのまま残す。WebGL復旧そのものはブラウザのネイティブ拡張で確認し、合成contextlostイベントを成功証拠にしない。

ローカルでブラウザの実行が制限されているため、ブラウザ結果はDraft PRの既存CIで確認する。定義追加だけを成功としない。最終の対象SHA・実行結果はPRとCI記録を正本とする。

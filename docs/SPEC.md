# ファイトフライト 仕様と作業判断

対象：`chameleonjp-lab/faitofuraito`。今回の改修は既存 `main` を基点にする。根拠は利用者の追加依頼。操作感・難易度・描写の最終採用は利用者本人が判断する。

## 今回の確定仕様

| 依頼 | 内容 | 受入条件 |
| --- | --- | --- |
| ① | 結果からホーム | 短い画面でもホームボタンへスクロールして戻れる |
| ② | レーダーの実用性と整合 | 実座標と機首方位を使い、前後・左右・高度差・最寄距離を示す。範囲外の生存敵も方向を表示 |
| ③④ | 命中と被弾の専用SE | 自弾命中と撃墜は従来のノイズパルスへ戻し、自機被弾は低い衝撃と警告音。消音・停止を尊重 |
| ⑤ | 減速中の宙返り | 最低飛行速度でも開始できる。完了時のみ加点し、再使用待ちと被弾は維持。旋回・上昇・加減速の操作で即時中断し、通常姿勢へ戻して同じ入力を続ける |
| ⑥ | 敵の高度へ到達 | プレイヤーの上昇角を敵より広くし、高い位置の敵を追える |
| ⑦ | 敵追加アナウンス | 敵機を実際に追加したイベントから画面上部に表示。初回出撃も案内 |
| ⑧ | 最後の敵を撃墜後3秒で補充 | ゲーム時間3秒後。停止中は進まず、通常追加と同時に二重出撃しない |
| ⑨ | イージーモード | 敵周辺へ操縦補助、画面外の敵を捉えるための旋回強化。中心の細い円内の敵に自動射撃、弾数無制限、操作ボタンは宙返りのみ。触った位置の操作キーで操縦 |
| ⑩ | イージー5分 | 有効プレイ時間300秒で終了。一時停止を含めない |
| ⑪ | ノーマル無制限 | 時間では終了せず、手動射撃・有限弾数・4操作ボタンを維持 |
| ⑫ | 結果共有 | 見やすい記録と内訳、モードとURLを含む改行テキスト。共有または明示的なコピー、非対応時は選択コピー |
| ⑬ | 実験場へのリンク | 結果から `https://chameleonjp-lab.github.io/chameleonjp_lab/` へ |
| ⑭ | SNSサムネイル | 雲上で零戦風の2機が遠距離射撃、ゲーム名「ファイトフライト」。初期HTMLにOG/Twitter画像情報 |
| ⑮⑯ | 結果・ホーム設定 | 両モードの違いを説明し、モード別の操作配置・大きさ・透明度を保存できる |
| ⑰ | プレイ中の設定 | 一時停止した現在のモードだけを編集。選択UIと処理の両方で制限 |
| ⑱ | 低高度警告 | 高度500m以下で警告を表示し、10秒以内に上昇できなければゲームオーバー |
| ⑲ | 任意名とランキング | 名前なしでも両モードを開始できる。名前ありは自動でランキング登録、名前なしはランキング外としてプレイ回数だけ記録 |
| ⑳ | 実験場ランキング | ノーマル／イージーを別ランキングとして実験場へ登録し、結果画面の得点直下に上位30位を表示 |

実験場へのリンクとランキング台帳は `ranking-manifest.json` と `docs/ranking/20260929_faitofuraito.sql` で照合する。

## モードと操作

| 項目 | ノーマル | イージー |
| --- | --- | --- |
| 時間 | 無制限・経過時間を表示 | 5分・残り時間を表示 |
| 射撃 | ボタンを押して発射 | 中央の円内の生存敵へ自動発射 |
| 弾数 | 7.7mm 1,000発＋20mm 120発 | 消費しない。発射数は記録する |
| 操作ボタン | 射撃・宙返り・加速・減速 | 宙返り |
| 操縦 | 触った位置からドラッグ＋画面外の敵を捕捉するまで旋回強化。画面内に捕捉したら通常応答へ戻る | 同左＋敵周辺への補助・画面外捕捉時の旋回強化 |
| 終了 | 被撃墜・弾切れ | 被撃墜・時間切れ |

イージーの補助は敵の座標へ固定しない。円内では追加補正を止め、周辺や進行方向への狙いはプレイヤーが操作する。弾道・命中判定は実際の位置と速度を使い、弾を曲げたり自動命中にしない。円は画面短辺の24%の直径、射程は1,200m。描画カメラと同じ投影式を使い、移動後の座標で発射直前に判定する。

## 維持する仕様と仮設定

以下の数値は取り消し可能なゲーム設定であり、史実性能・利用者の難易度承認とは扱わない。

- 得点 = `max(0, 撃墜数×1,000 + floor(撃墜数×1,000×max(0,1−発射数/1,120)) + 完了宙返り数×150 − 被害HP×10)`。実際に失ったHPだけを減点し、過剰ダメージは数えない。両モードとも同じ式だが結果・共有にはモードを明記する。
- 零戦二一型（A6M2）を基にした機体。後方斜め上の三人称、空のステージ、低速で小回り・高速で操縦力低下。厳密な空力・燃料・離着陸は対象外。
- プレイヤーの最大ピッチ0.95rad、敵0.62rad。速度65〜141m/s。宙返り約5秒、再使用待ち2秒、開始最低速度65m/s。途中終了は加点せず、宙返り中も被弾する。手動の旋回・上昇・加減速で中断し、通常姿勢へ復帰してその入力を同じ更新で適用する。
- 通常は14秒間隔・最大5機まで敵を追加。最後の生存敵撃墜時には通常追加より3秒後の補充を優先する。残る墜落機は生存敵に数えない。
- 敵は各機1,000＋120発、弾切れ後は逃げる。HP70%以下で速度倍率0.9、50%以下0.8、30%以下0.65＋煙。撃墜後は5秒の炎煙と墜落、得点は一度だけ。
- レーダーは機首を上にした水平地図、半径3km・1km目盛り。高度差は別の上下印、最寄敵は距離と高度差の数値も表示。範囲外は外周の三角、弾切れ敵は中抜き。実機の装備ではない。
- 通常の最後の弾は飛行中なら寿命（最長1.5秒）まで解決して結果を確定。同時終了の優先は被撃墜→時間切れ（イージーのみ）→弾切れ（ノーマルのみ）。
- 60Hz固定更新。非表示・フォーカス喪失・手動停止で入力・本体・音を停止し、明示的な再開で戻る。1秒を超える描画停止も通知して一時停止する。
- 名前は任意・最大20文字。ランキング登録には名前が必要で、名前なしプレイはランキング外のまま開始時のプレイ回数だけ記録する。操作設定は端末の同じブラウザにモード別で保存。既存ノーマル保存キーを維持。保存前の編集をキャンセルすると両モードの下書きを破棄する。
- 音はコードによる合成効果音。ホーム・結果・一時停止で切り替え。再生失敗でもゲームを続行。終了の直前に発生したSEだけ短い余韻を許し、ホーム・消音・停止では即時停止。
- 共有はユーザー操作からのみ開始。確定結果から作る文章にゲームURLを直書きする。共有の取消しを失敗やコピー成功と扱わない。再出撃・ホームへ移動後の古い非同期応答で画面を更新しない。
- 高度が500m以下になったら10秒の警告タイマーを開始し、500mを超えて回復したら解除する。タイマーが満了した結果は `low-altitude` として扱う。
- ランキングはモード別の `faitofuraito_normal` / `faitofuraito_easy` を使用する。名前ありは開始・終了・冪等なスコア送信を行い、名前なしは既存のゲスト開始RPCでプレイ回数だけを記録する。名前なしにはスコア行を作らず、通常ランキングから除外する。

## 構造と検査

`simulation.ts` が時刻・移動・敵・弾・損傷・得点・終了を所有。`flight-assist.ts` は補助と発射条件、`flight-view.ts` はカメラ・照準の共通投影、`scene.ts` / `aircraft.ts` は描画、`radar.ts` は実座標のレーダー、`input.ts` は入力、`control-settings.ts` は設定、`sharing.ts` は共有文章とブラウザ境界、`main.ts` は画面遷移と固定更新、`audio.ts` は音を所有する。

結果中は撃墜済み機体の残る墜落演出だけ進める。得点・ゲーム時間・生存敵・弾を変更しない。一時停止中は墜落演出も停止。描画乱数で勝敗を変えない。本番には状態注入・結果改変の検査用入口を含めず、開発時だけ深いコピーの読取スナップショットを使う。

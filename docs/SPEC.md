## 実装用の仮設定（proposed）

ユーザーの未指定箇所を取り消し可能な初期値として実装する。下記を史実値・本人承認済みとは扱わない。

- P01：零戦二一型（A6M2）を基準。操縦補助のある飛行計算。低速では機動性を残し、高速では操作を弱め、旋回・上昇・宙返りで速度を失う。離着陸・燃料切れ・実機操縦装置は対象外。
- P02：得点 = `撃墜数×1,000 + floor(撃墜数×1,000×max(0,1−消費弾数/1,120)) + 完了宙返り数×150`。0撃墜・0宙返りなら0点。弾を撃たずに待つだけで節弾点は得られない。
- P03：7.7mm機銃合計1,000発、20mm機関砲合計120発。両方を同じボタンで射撃、弾は1発ずつ消費計上。実機の搭載数に基づくが、周期・弾速・損傷量はゲーム用。
- P04：最後に発射した弾の結果を失わないよう、自機弾が飛行中なら弾の寿命（最長1.5秒）まで解決してから弾切れ結果を確定。同じ更新で終了条件が重なれば、自機撃墜→時間切れ→弾切れの順。
- P05：宙返りは約5秒、再使用待ち2秒、開始速度85m/s以上。宙返り中も被弾する。途中終了は加点しない。無敵や瞬間移動はない。
- P06：本体は60回/秒の固定更新、ゲーム中の有効時間を180秒数える。非表示・フォーカス喪失・手動停止では入力・本体・音を停止し、利用者の再開操作で戻る。1秒超の画面停止は一時停止として通知し、時間や敵を一気に進めない。
- P07：敵は最大5機、14秒間隔で追加。接近128m/s・回避122m/s・弾切れ逃走132m/s（自機と共通の上限141m/s内）。初期機には1.5秒の直進猶予。射程と機首方向が合った場合のみ実弾を発射。弾は動く対象への相対線分で判定し、毎更新の点判定による通り抜けを避ける。
- P08：レーダーの表示範囲は自機から1.4km。明るい菱形が敵、空の菱形が弾切れ敵、縦の線が高低差。自機の姿勢を基準に前後を表示する。実機装備としてのレーダーではない。
- P09：効果音は任意の補助。機関音・射撃・命中・撃墜をコードで合成し、ミュートを用意。実機録音とはしない。再生失敗だけでプレイを止めない。
- P10：名前を必須入力（最大16文字）。名前は画面表示にだけ用い、外部送信しない。ランキング・プレイ集計・共有は今回追加しない。

## 構造と責任

`simulation.ts` が時刻、乱数、移動、敵行動、弾、命中、得点、終了を所有する。`scene.ts` / `aircraft.ts` は表示、`radar.ts` は立体レーダー、`input.ts` は指ごとの入力、`main.ts` は画面遷移と固定更新、`audio.ts` は音の生成と停止を所有する。

本番出力には状態注入や結果改変の検査用入口を含めない。開発時だけ深いコピーの読取専用スナップショットを用意し、実際のボタン操作と対応づけて観測する。

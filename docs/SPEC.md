## モードと操作

ホーム画面を初めて開いたときはイージーを選び、モード選択はイージー、ノーマルの順で表示する。名前欄の中に出す文言は「名前」のみとする。下の説明文はそのまま残す。

| 項目 | ノーマル | イージー |
| --- | --- | --- |
| 時間 | 無制限・経過時間を表示 | 5分・残り時間を表示 |
| 射撃 | ボタンを押して発射 | 中央の円内の生存敵へ自動発射 |
| 弾数 | 7.7mm 1,000発＋20mm 120発 | 消費しない。発射数は記録する |
| 操作ボタン | 射撃・宙返り・加速・減速 | 宙返り |
| 操縦 | 触った位置からドラッグ＋敵を画面に捉えるまで旋回強化 | 同左＋敵周辺への照準補助 |
| 終了 | 被撃墜・機体接触・弾切れ・低高度警告10秒後 | 被撃墜・機体接触・時間切れ・低高度警告10秒後 |

イージーの補助は敵の座標へ固定しない。円内では追加補正を止め、周辺や進行方向への狙いはプレイヤーが操作する。弾道・命中判定は実際の位置と速度を使い、弾を曲げたり自動命中にしない。円は画面短辺の27%の直径（旧24%から小幅に拡大）、射程は1,200m。自動射撃時だけ敵の現在の速度・方向から着弾先を予測し、銃口から直線弾を発射する。機首からの補正上限は0.16rad、予測時間は弾の寿命1.5秒以内。発射後の弾は追尾しない。描画カメラと同じ投影式を使い、移動後の座標で発射直前に判定する。

## 維持する仕様と仮設定

以下の数値は取り消し可能なゲーム設定であり、史実性能・利用者の難易度承認とは扱わない。

- 得点 = `max(0, 射撃による撃墜数×1,000 + floor(射撃による撃墜数×1,000×max(0,1−発射数/1,120)) + 完了宙返り数×150 − 被害HP×10) + 接触撃墜数×1,000`。実際に失ったHPだけを減点し、過剰ダメージは数えない。両モードとも同じ式だが結果・共有にはモードを明記する。
- 零戦二一型（A6M2）を基にした機体。後方斜め上の三人称、空のステージ、低速で小回り・高速で操縦力低下。厳密な空力・燃料・離着陸は対象外。
- プレイヤーの最大ピッチ0.95rad、敵0.62rad。速度65〜141m/s。宙返り約5秒、再使用待ち2秒、開始最低速度65m/s。途中終了は加点せず、宙返り中も被弾する。
- 通常は14秒間隔・最大5機まで敵を追加。最後の生存敵撃墜時には通常追加より3秒後の補充を優先する。残る墜落機は生存敵に数えない。
- 敵は各機1,000＋120発、弾切れ後は逃げる。HP70%以下で速度倍率0.9、50%以下0.8、30%以下0.65＋煙。撃墜後は5秒の炎煙と墜落、得点は一度だけ。
- レーダーは機首を上にした水平地図、視認範囲と同じ1.5km・500m目盛り。高度差は別の上下印、最寄敵は距離と高度差の数値も表示。高度差を含む実距離で範囲内外を判断する。画面内は塗りつぶし、画面外は中抜き、範囲外は外周の三角。弾切れ敵は従来どおり中抜き。実機の装備ではない。
- 通常の最後の弾は飛行中なら寿命（最長1.5秒）まで解決して結果を確定。機体接触は移動後・新たな射撃や飛行中の弾の解決前に確定し、＋1,000点で即終了。接触以外の同時終了の優先は被撃墜→低高度期限→時間切れ（イージーのみ）→弾切れ（ノーマルのみ）。
- 60Hz固定更新。非表示・フォーカス喪失・手動停止で入力・本体・音を停止し、明示的な再開で戻る。1秒を超える描画停止も通知して一時停止する。
- 名前は任意。ランキング対象は前後の空白を除いた1〜20文字で出撃したプレイ。空欄は名前未登録として回数だけ記録する。操作設定は端末の同じブラウザにモード別で保存。既存ノーマル保存キーを維持。保存前の編集をキャンセルすると両モードの下書きを破棄する。
- 音はコードによる合成効果音。ホーム・結果・一時停止で切り替え。再生失敗でもゲームを続行。終了の直前に発生したSEだけ短い余韻を許し、ホーム・消音・停止では即時停止。
- 共有はユーザー操作からのみ開始。確定結果から作る文章にゲームURLを直書きする。共有の取消しを失敗やコピー成功と扱わない。再出撃・ホームへ移動後の古い非同期応答で画面を更新しない。

## 追加改修の受入条件（2026-09-29）

- **承認済み**：宙返り途中の新たな操縦入力で中止し、その時点の位置から姿勢を戻しながら操作を続ける。中止した宙返りは加点せず、再使用まで2秒待つ。開始前から保持していた操縦は開始を妨げず、開始後の新しい操縦で中止する。両モードで画面外の敵を捉えるまで旋回を強め、画面内へ入った時点で強化を解除する。ノーマルへ自動射撃や照準の自動補正は加えない。
- **承認済み**：一定高度以下で警告し、警告からゲーム時間10秒後に終了する。**仮設定**：境界は1,200m。警告は一度開始したら上昇しても解除しない。停止中は残り秒数を進めない。

- **承認済み**：テスト記録を残さない。サーバー試験はロールバックするトランザクションを優先し、実際に残ったテスト行がある場合だけ識別して削除する。実利用者の記録は変更しない。

モード別識別子は `faitofuraito_normal` / `faitofuraito_easy`。名前ありは既存の開始→終了→重複しない得点送信を使用し、名前なしは専用の開始記録だけを使用する。実装契約は `public/ranking-manifest.json`。名前なしの人数は識別できないため、回数は加えるが、別人の人数を推測して増やさない。

## 構造と検査

`simulation.ts` が時刻・移動・敵・弾・損傷・得点・終了を所有。`flight-assist.ts` は補助と発射条件、`flight-view.ts` はカメラ・照準の共通投影、`scene.ts` / `aircraft.ts` は描画、`radar.ts` は実座標のレーダー、`input.ts` は入力、`control-settings.ts` は設定、`sharing.ts` は共有文章とブラウザ境界、`main.ts` は画面遷移と固定更新、`audio.ts` は音を所有する。

結果中は撃墜済み機体の残る墜落演出だけ進める。得点・ゲーム時間・生存敵・弾を変更しない。一時停止中は墜落演出も停止。描画乱数で勝敗を変えない。本番には状態注入・結果改変の検査用入口を含めず、開発時だけ深いコピーの読取スナップショットを使う。

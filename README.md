# ファイトフライト

スマートフォンの縦画面で遊ぶ、零戦二一型を題材にした空戦ゲームです。ノーマルは時間無制限、イージーは5分間。

## どんなゲーム？

戦闘機で空を自由に飛び、次々と現れる敵機を追ってハイスコアを目指す、1人用の3D空戦ゲームです。敵をすべて倒してクリアする形式ではなく、狙いを定めて撃つこと、攻撃をかわして飛び続けることを楽しみます。

- **目標**：敵機の撃墜、弾の節約、宙返りで得点を伸ばし、被弾による減点を抑えます。
- **イージー**：5分間のスコアアタック。巡航と自動射撃の補助があるため、まず操縦に慣れたい人向けです。
- **ノーマル**：時間無制限で、射撃と速度も自分で操作します。
- **終了条件**：HPがなくなる、敵機と衝突する、低高度警告から10秒が経過すると終了します。低高度警告は上昇しても解除されません。

[ブラウザでファイトフライトを開く](https://chameleonjp-lab.github.io/faitofuraito/)

ホームでモードを選び、必要なら「ルールと操作方法」を確認して出撃してください。タッチ画面では空の部分をドラッグして操縦し、PCではキーやマウスを使えます。名前の入力は任意ですが、名前ありのプレイはオンラインランキングへの登録対象です。名前なしでもプレイ回数の記録があるため、「名前なし＝外部通信なし」ではありません。以下に操作・記録の詳しい説明と開発情報をまとめています。

READMEはソース側の説明です。公開ページの版は異なる場合があるため、公開版のルールはゲーム内説明も確認してください。

## 操作と記録

空を触ると現れる操作キーで操縦します。ノーマルは射撃・宙返りの2ボタンと上下の速度レバーで操作し、手動射撃です。レバーを離すと中央へ戻り、調整した速度を保持します。イージーは操縦補助と円内の敵への自動射撃、宙返りボタンのみです。両モードとも7.7mm 288発・20mm 96発を使い切ると6秒で再装填します。撃墜・節弾・完了した宙返りで加点し、被弾で減点します。ホーム・結果画面でモード別の操作設定を保存でき、一時停止中は現在のモードだけを編集します。宙返り中の新しい操縦で中止し、その場から操縦を続けられます。高度1,200m以下では警告し、10秒後に終了します。結果はURLを含む文章として共有できます。

名前なしでも遊べます。出撃前に名前を入れたプレイはモード別ランキングへ登録し、名前なしは順位対象外として回数だけ数えます。結果に同じモードの上位30位を表示します。

PCではキーボードまたはマウスのドラッグで操縦できます。操作設定からキーを変更でき、タッチ用の配置設定も切り替えて使えます。「ルールと操作方法」はホームと一時停止画面から開けます。最新の共通操作の同期範囲と検査は[SHARED_CONTROLS_SYNC.md](docs/SHARED_CONTROLS_SYNC.md)を参照してください。

[ゲームを開く](https://chameleonjp-lab.github.io/faitofuraito/)

## 開発

Node.js 22.12以上を使用します。

```sh
npm ci
npm run dev
npm test
npm run build
```

成果物は `dist/` です。相対パスで出力するため、GitHub Pagesの `/faitofuraito/` 配下にも配置できます。公開済みのGitHub Pagesは `gh-pages` の成果物を配信します。公開元のソースコミットは `deployment.json` に記録します。
